# Subprocessors and Service Providers

Last updated: 2026-05-08

Weave uses third-party providers to operate the product.

## Current Providers

- ** Clerk ** - authentication and user account management.
- **Vercel** - application hosting and web analytics.
- **Vercel Blob** - user avatar file storage.
- **MongoDB** - data storage for game content.

## Notes

- Provider list may change over time as the product evolves.
- We aim to use providers with industry-standard security practices.
